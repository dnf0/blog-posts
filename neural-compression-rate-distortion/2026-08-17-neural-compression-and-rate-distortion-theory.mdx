**TL;DR:** Classical compression relies on discrete lookup tables *T* mapped to fixed alphabet symbols. Modern Neural Compression replaces these tables with deep autoencoders and learned vector quantization (VQ-VAE). By evolving classical Transform Coding from handcrafted linear projections (like DCT or Wavelets) into learned non-linear neural networks, neural codecs optimize a unified end-to-end Lagrangian objective: *ℒ(x) = λ · ρ(x, g(q(f(x)))) − log₂ p'(q(f(x)))*, balancing reconstruction distortion *D* against the Shannon entropy rate *R*.
</Callout>

In [our previous post](/blog/2026-08-16-shannon-entropy-and-lossless-compression), we explored how Claude Shannon's source coding theorem establishes the foundation of lossless compression: by assigning variable-length binary codewords in a lookup table *T* inversely proportional to symbol probabilities (*bᵢ ≈ −log₂ pᵢ*), an encoder can transmit discrete sequences at the entropy limit without discarding a single bit of information.

However, when dealing with continuous, high-dimensional real-world data—such as multispectral Earth observation rasters, climate reanalysis grids, or high-resolution video streams—classical lookup tables completely fail. The number of possible pixel combinations explodes exponentially (*M → ∞*), and signals contain pervasive non-linear spatial and temporal correlations that independent frequency counters cannot exploit.

This post explores how **Neural Compression (NC)** solves this bottleneck by replacing static tables with continuous neural networks, vector quantization, and rate-distortion Lagrangian optimization.

## 1. Replacing the Lookup Table: Autoencoders and Quantization

In classical lossless compression, we relied on a simple premise: count how often each symbol appears in a sequence and store their binary codewords in a lookup table *T*.

This lookup table approach works perfectly for small, discrete alphabets (such as ASCII text or 4-state weather logs). But when dealing with continuous, high-dimensional real-world data—such as satellite imagery, climate grids, or audio waveforms—the table approach breaks down completely:
* **The Combinatorial Explosion:** A single 1024 × 1024 image contains over one million pixels. Even if each pixel has only 256 brightness levels, the number of distinct possible images is 256^(1,000,000)—far exceeding the number of atoms in the observable universe. We cannot count frequencies or store a table with billions of rows.
* **Continuous Values:** Scientific sensors record continuous physical measurements (temperatures, radiances, wind velocities) with decimals, rather than discrete integers from a fixed list.

Neural Compression solves this by replacing static tables with two deep neural networks that learn how to **summarise** and **reconstruct** signals from data statistics [1](#references).

![Figure 1: Comparison between classical discrete lookup table T and modern neural non-linear autoencoder with latent quantization.](/images/neural-compression/01_lookup_to_neural.png)

### The Autoencoder: A Narrow Information Bottleneck

Instead of memorising every possible signal in a table, we train two neural networks that work as a team:

1. **The Encoder Network (*f*<sub>*θ*</sub> — The Summariser):**
   * Takes the raw high-dimensional input signal *x* (e.g. an image containing *n = 1,000,000* raw pixel values) and compresses it down to a compact bottleneck array of *m* numbers (*m ≪ n*, e.g. *m = 1,000*).
   * This compact array *z* = *f*<sub>*θ*</sub>(*x*) = `[z₁, z₂, ..., zₘ]` is called the **latent representation** or **bottleneck embedding** (from the Latin *latere*, meaning "hidden", because rather than raw pixels, these numbers capture the hidden structural features of the data—such as edge orientations, terrain slopes, and spectral textures).
   * The subscript *θ* represents the adjustable internal parameters (weights) of the neural network.

2. **The Decoder Network (*g*<sub>*ϕ*</sub> — The Reconstructor):**
   * Receives only this compact bottleneck array *z* and attempts to reconstruct an estimate of the original full signal, producing *x'* = *g*<sub>*ϕ*</sub>(*z*) ≈ *x*.
   * The subscript *ϕ* represents the decoder's adjustable weights.

Connecting the encoder and decoder back-to-back (*g*<sub>*ϕ*</sub> ∘ *f*<sub>*θ*</sub>) creates an **Autoencoder (AE)**—named "auto" (self) because its sole training objective is to reconstruct its own input through a narrow dimensional bottleneck.

> [!NOTE]
> **What about Variational Autoencoders (VAEs)?**  
> In a standard autoencoder, the encoder maps an input to a single rigid point in the bottleneck space. A **Variational Autoencoder (VAE)** [2](#references) trains the encoder to output a smooth probability distribution instead (a mean center and variance spread). This prevents empty gaps in the feature space and ensures that nearby latent points produce smooth, coherent reconstructions.

### The Digital Bottleneck: Why We Need Quantization

There is an immediate catch: neural networks operate on **continuous real numbers** (32-bit floating-point decimals like `0.784291...`).

Transmitting continuous floating-point numbers across a network requires infinite precision. If your compressed bottleneck array *z* contains 1,000 numbers, and each number is stored as a 32-bit float, you must transmit 32,000 bits—which defeats the purpose of compression!

To store or transmit data across digital communication channels, the continuous array *z* must be mapped to a finite set of discrete integers. This rounding step is called **Quantization** (*q*):

```text
ẑ = q(z) = q(f_θ(x))
```

Think of quantization as snapping continuous values to the nearest mark on a ruler (e.g., rounding `2.73` to `3`). 

This step has two profound implications:
1. **It introduces deliberate information loss:** Because fine decimal details are rounded off, we cannot perfectly reconstruct the exact original signal (*x'* ≈ *x*). This is the exact mechanism by which we trade quality for file size.
2. **It restores Shannon's lossless coding:** Because *ẑ* is now an array of discrete integers from a finite alphabet, we can once again apply Shannon's entropy algorithms (such as Arithmetic Coding) to losslessly pack those integers into minimal binary bits.

## 2. Vector Quantization and VQ-VAEs

Rather than rounding each individual number (scalar) in the bottleneck array *z = [z₁, z₂, ..., zₘ]* independently, advanced neural compressors group numbers into coordinate chunks (feature vectors) and snap them to the nearest predefined anchor point in a learned dictionary (**codebook**).

In a **Vector Quantized-VAE (VQ-VAE)** [3](#references), the model maintains a codebook of *K* learnable *D*-dimensional feature vectors:

```text
Codebook C = { z⁽¹⁾, z⁽²⁾, ..., z⁽ᴷ⁾ } ⊂ ℝᴰ
```

During the forward pass, the continuous encoder output *z* = *f*<sub>*θ*</sub>(*x*) is mapped to the single closest codebook vector in Euclidean distance:

```text
ẑ = z⁽ᵏ*⁾  where  k* = argmin_k ‖ z − z⁽ᵏ⁾ ‖₂
```

![Figure 2: Vector Quantization in 2D latent space: continuous encoder features snap to nearest learned codebook centroids.](/images/neural-compression/02_vq_vae_codebook.png)

Instead of transmitting the full continuous vector *z*, the encoder only needs to transmit the discrete integer index *k\** from the set `[1, ..., K]`. The receiver looks up index *k\** in its identical local codebook copy and feeds vector *z⁽ᵏ*⁾* directly into the neural decoder *g*<sub>*ϕ*</sub>.

## 3. The Transform Coding Paradigm

Most modern Neural Compression methods can be viewed as learned, non-linear variations of the classical **transform coding paradigm** [1, 4](#references).

In traditional lossy codecs such as JPEG (Discrete Cosine Transform / DCT) and JPEG 2000 (Discrete Wavelet Transform / DWT), compression follows four foundational steps:

![Figure 5: The Transform Coding Framework: Non-linear analysis and synthesis neural networks coupled with learned entropy modeling.](/images/neural-compression/05_transform_coding_paradigm.png)

### 1. Analysis Transform (*f*)
Raw input data *x* consists of highly correlated coordinates (e.g. neighbouring pixels in an elevation raster or satellite band share nearly identical values). These correlations introduce structural redundancies. 
* **Traditional Codecs:** Apply a handcrafted, linear, invertible transform (Fourier, DCT, Wavelet) to decorrelate the coordinates.
* **Neural Compression:** Employs an artificial neural network *f*<sub>*θ*</sub> acting as the **analysis transform**. Because it is non-linear and parameterized by deep layers, *f*<sub>*θ*</sub> discovers intricate data manifolds that linear matrix multiplications cannot capture.

### 2. Quantization (*q*) — Where Information Is Discarded
In any lossy compression pipeline, transforms alone (whether DCT or neural networks) do not discard data—they only reorganize it. **Quantization is the only step in the entire pipeline where information is permanently discarded to save bits:**

```text
ẑ = q(z) = round(z)
```

When continuous numbers are rounded to the nearest integer grid (e.g. rounding `1.24` and `0.81` both down to `1`), the fine decimal differences are permanently erased:
* **The Benefit (Lower Bitrate / Rate *R*):** When numbers collapse into discrete integers—especially zeros—they become highly predictable and repetitive, requiring far fewer bits to store.
* **The Cost (Higher Error / Distortion *D*):** The decoder can never recover the exact original decimals, leading to approximation error between *x* and *x'*.

#### How Neural Networks "Warp" the Bottleneck Space
In classical JPEG, humans manually designed a static "quantization table" to decide which frequencies to discard. 

In Neural Compression, the encoder *f*<sub>*θ*</sub> learns this automatically during training:
* **Critical Features (e.g. sharp edges, coastlines):** The encoder *amplifies* (stretches) these values across wide ranges so they cross multiple integer steps and survive the rounding process with high fidelity.
* **Irrelevant Details (e.g. imperceptible background sensor noise):** The encoder *squashes* these values close to zero, causing them to collapse entirely into `0` during rounding. They consume zero bits, with virtually no perceptible impact on reconstruction quality.

### 3. Entropy Modeling (*p'*) & Lossless Coding
After quantization, discrete string *ẑ* is compressed losslessly using entropy coding (e.g. Arithmetic Coding [5](#references) or Asymmetric Numeral Systems).
Because the true distribution *p(ẑ)* is unknown, the system fits a learned parametric **entropy model** *p'*. The closer *p'* matches *p*, the closer the operational code length approaches Shannon's theoretical minimum.

### 4. Synthesis Transform (*g*)
To reconstruct the signal on the receiving side, an inverse mapping is applied to *ẑ*.
In neural compression, an analytical inverse of *f*<sub>*θ*</sub> does not exist. Instead, a second neural network—the **synthesis transform** *g*<sub>*ϕ*</sub> (the decoder)—is trained to reconstruct the original data, producing approximation *x'* = *g*<sub>*ϕ*</sub>(*ẑ*).

## 4. Rate-Distortion Theory & Lagrangian Optimization

The performance of any lossy codec is governed by two competing objectives:
1. **Minimising Rate (R):** Transmitting the fewest possible bits (maximising compression).
2. **Minimising Distortion (D):** Keeping the reconstructed signal *x'* as close to original signal *x* as possible.

We express this fundamental trade-off as a **Lagrangian optimization problem** [1](#references):

```text
min  ℒ = λD + R                                  (4)
```

Where:
* **R (Rate):** The expected number of bits required to transmit the encoded representation *ẑ*.
* **D (Distortion):** The expected reconstruction error between input *x* and output *x'*, defined by an error metric *E[ρ(x, x')]*.
* **λ (Lagrange Multiplier):** A hyperparameter that dictates the operational trade-off:
  * When *λ → 0*, the optimizer prioritises minimizing bits above all else, producing tiny files at the cost of high blur/distortion.
  * When *λ → ∞*, the optimizer penalises even the smallest reconstruction errors, demanding high bitrates.

## 5. The Complete End-to-End Objective Function

Combining the analysis transform *f*<sub>*θ*</sub>, quantizer *q*, synthesis transform *g*<sub>*ϕ*</sub>, and entropy model *p'*, we can formulate the complete loss function for a single input *x* [1](#references):

```text
ℒ(x) = λ · ρ(x, g_ϕ(q(f_θ(x)))) − log₂ p'(q(f_θ(x)))
       ╰──────────┬───────────╯   ╰─────────┬────────╯
           Distortion Term D           Rate Term R
```

This single loss function coordinates three distinct learning dynamics simultaneously:

1. **Distortion Gradients (*D*):** The error *ρ(x, x')* produces gradients that flow through decoder *g*<sub>*ϕ*</sub> and encoder *f*<sub>*θ*</sub>. This pushes the encoder to produce quantization-robust representations that the decoder can invert with high fidelity.
2. **Rate Gradients (*R* on Encoder):** The term *−log₂ p'(ẑ)* pushes the encoder *f*<sub>*θ*</sub> to place latents in high-density regions of the entropy model, creating easily compressible representations with low Shannon entropy.
3. **Entropy Model Fitting (*R* on *p'*):** Because the entropy model *p'* only appears in the rate term, its parameters receive gradients exclusively from *−log₂ p'(ẑ)*. This forces *p'* to dynamically track and match the true empirical distribution of the quantised latents *ẑ*.

## 6. The Rate Term: Entropy as a Differentiable Loss

From Shannon's source coding theorem, the theoretical lower bound on the number of bits required to encode quantised latents *ẑ* losslessly is given by its self-information [1](#references):

```text
−log₂ p(ẑ)                                       (5)
```

Taking the expectation over the latent probability distribution yields the Shannon Entropy:

```text
R = E[ −log₂ p(ẑ) ]                              (6)
```

While entropy *H(ẑ)* represents the theoretical floor rather than the exact operational rate produced by a specific file format, modern entropy coding algorithms (such as Range Asymmetric Numeral Systems) achieve operational bitrates within **0.1%** of this theoretical limit.

### Making Quantization Differentiable

During neural network training, standard rounding *ẑ = ⌊z⌉* has zero derivative almost everywhere (`d⌊z⌉/dz = 0`), which blocks gradient backpropagation.

Modern neural codecs bypass this using two main approaches:
1. **Uniform Noise Substitution (Ballé et al. [6](#references)):** During training, quantization is simulated by adding continuous uniform noise: *z̃ = z + U(−0.5, 0.5)*. This provides continuous non-zero gradients everywhere while matching the marginal statistics of grid rounding.
2. **Straight-Through Estimator (STE) [3](#references):** In the backward pass, the gradient of the quantizer is approximated as an identity operator (`∂ẑ/∂z ≈ 1`), allowing gradients to flow directly from the decoder into the encoder.

## 8. Practical Distortion Metrics: MSE vs. SSIM

The distortion term *D = E[ρ(x, x')]* measures the mathematical distance between original data and reconstruction:

### 1. Mean Squared Error (MSE) / L2 Loss
For an image with *N* pixels, MSE computes the average squared difference:

```text
MSE(x, x') = (1 / N) ∑ (xᵢ − x'ᵢ)²
```

While computationally fast and differentiable, MSE penalises high-frequency textures equally regardless of whether downstream models or human observers find them informative.

### 2. Structural Similarity Index Measure (SSIM)
SSIM [7](#references) models structural perception by comparing local luminance, contrast, and correlation:

```text
SSIM(x, x') = [ (2μ_x μ_x' + c₁) (2σ_xx' + c₂) ] / [ (μ_x² + μ_x'² + c₁) (σ_x² + σ_x'² + c₂) ]
```

In scientific and geospatial domains, researchers frequently augment MSE with domain-specific metric penalties (such as spectral angle mappers or downstream segmentation task losses) to ensure neural compression preserves physical analytics utility.
